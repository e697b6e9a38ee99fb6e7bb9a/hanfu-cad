# 使用说明 · 对穿交半臂（尺码工具 + CAD 出图）

## 一、一条命令出图

```bash
cd pattern

# 单码（男 M，厂商基准）
python make.py --sex 女 --size M

# 整档（女 XS~2XL 共 6 个码）
python make.py --sex 女 --all

# 换基准：vendor=厂商实物表（默认，最高置信度） / artifact=文物复原版
python make.py --sex 女 --size M --profile artifact

# 男装
python make.py --sex 男 --all

# 直接给净尺寸（身高 163、净胸围 86）
python make.py --sex 女 --height 163 --bust 86

# 放量档：紧身 / 合体 / 宽松
python make.py --sex 男 --size 175/92A --ease 宽松

# 指定输出目录
python make.py --sex 女 --all --out ../out
```

产物（`out/<码>/`）：

| 文件 | 内容 |
|---|---|
| `对穿交_半臂_<性别>_<码>.svg` | 裁片图，mm 单位，六图层 |
| `对穿交_半臂_<性别>_<码>.dxf` | **CAD 图**，mm（INSUNITS=4），分 5 个图层 |
| `…pieces.json` | 几何侧车（供二次开发） |

另在 `out/尺码表_vendor_男装.md` 汇总各码尺寸（厂商表为男装）。

## 一·补、两套基准

| 性别 | 自动基准 | 依据 | 中码（M） |
|---|---|---|---|
| **女** | `artifact` | 钱樟墓文物复原（已过审 v6） | 衣长 825 ｜ 平铺胸宽 822 ｜ 摆宽 1150 ｜ 袖口 195 ｜ 领缘 40 |
| **男** | `vendor` | 厂商实物出货表（最高置信度） | 衣长 770 ｜ 平铺胸宽 570 ｜ 摆宽 798 ｜ 袖口 160 ｜ 领缘 70 |

`--profile` 不填时按性别自动选；要覆盖就显式传值。

厂商表缺的三项：**下摆 = 胸宽×1.40（已确认为正确）**、腋深 = 衣长×0.36、交叠 270。

## 二、DXF 图层

| 图层 | 内容 | 颜色 |
|---|---|---|
| `CUT_轮廓` | 裁片净样闭合多段线 | 白/黑 |
| `GRAIN_布纹` | 布纹线（带箭头） | 灰 |
| `NOTCH_刀口` | 对位刀口 | 红 |
| `TEXT_文字` | 片名 ×数量 | 绿 |
| `DIM_标注` | 100mm 校验标尺 | 青 |

净版：**未含缝份**，裁布时自行加放（下摆 2–3cm、侧缝 1cm、领缘 1cm）。

## 三、尺码表从哪来

- 档差：GB/T 1335.1/.2-2008（身高 5cm、胸围 4cm 分档；女中间体 160/84A、男中间体 170/88A）
- 放量：女 8–10cm 合体 / 男 20–22cm 合身 —— **这一条是单一来源，置信度低**
- 每个参数的出处与置信度见 `verification/尺码资料核验.md`

**基准**：女 M（160/84A 合体）= 已过审的 v6 半臂，其余码都从它推，`make.py --sex 女 --size M` 出来的图与 v6 逐项一致（可当回归测试用）。

## 四、三个可调参数

`pattern/sizing.py` 顶部：

| 参数 | 含义 | 现值 |
|---|---|---|
| `GRADE` | 各项档差（mm / 每 cm 净尺寸） | 见文件注释 |
| `SEX[...]["extra_ease"]` | 男女放量差 | 女 0 / 男 110mm |
| `EASE` | 紧身/合体/宽松 系数 | 0.94 / 1.00 / 1.08 |

## 五、回归自检

```bash
python ../verification/verify.py          # 28 项尺寸/结构/形制自检（对当前 SVG）
python sizing.py                          # 打印男女全码尺寸表
```
