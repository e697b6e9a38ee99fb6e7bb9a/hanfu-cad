# 汉服 CAD 打版工具链 · 对穿交半臂 / 接袖 / 深衣型矩领

**把一件汉服实物逆向成可下厂的裁片图与 CAD 图纸。** 输入是博物馆官图、出土材料或厂商样衣；
输出是毫米级净版：`SVG` 裁片图 + `DXF`（CAD 可直接打开）+ 几何侧车 `JSON`，
带布纹方向、对位刀口和 100 mm 校验标尺。

仓库里有**三件成品的完整图纸**，以及生成它们的工具链：

| 成品 | 形制 | 裁法 | 尺码 |
|---|---|---|---|
| 对穿交 **半臂**（根目录） | 直领对襟的剪裁 ＋ 交领的穿法，袖口止于上臂 | 分裁 | 11 码（女 XS–2XL、男 S–2XL） |
| 对穿交 **接袖**（`jiexiu/`） | 同一件衣身，袖上多一道接袖缝 → 长袖 | 分裁 | 男装 5 码 |
| **深衣型矩领**（`shenyi/`） | 通裁：中段对折、布带两端即袖，无肩缝、无接袖缝 | 通裁 | V1 原衣 / V2 宽袖礼服 / V3 窄袖便服 |

**实物基准**：无锡七房桥钱樟夫妇墓 · 鸟衔花枝纹缎夹袄（明中后期，藏无锡博物院；
中国丝绸博物馆 2014–2018 保护修复）。

## 找汉服打版 / 制衣资料的话，这里就是

- **汉服制衣**：裁片图、纸样、样板、净版、缝份、布纹方向、对位刀口、排料
- **打版 / 放码**：GB/T 1335 档差、多码推档、按身高＋胸围直接出码
- **CAD 出图**：`DXF`（mm，`INSUNITS=4`，五图层 CUT / GRAIN / NOTCH / TEXT / DIM）、`SVG`，
  AutoCAD / LibreCAD / Illustrator 都能打开
- **传统服饰复原**：博物馆藏品、出土文物、服装史、形制考据、像素级叠合校验（IoU）
- **形制术语**：对穿交、直领、对襟、交领、右衽、半臂、接袖、通裁 / 分裁、深衣、矩领、腰线高低
- **实现**：Python ＋ ezdxf、三次贝塞尔、de Casteljau 切分、G1 混合圆角、28 项尺寸断言

英文检索词：hanfu, hanfu pattern, hanfu CAD, traditional Chinese clothing, sewing pattern,
garment pattern making, tailoring, DXF, SVG, ezdxf, dress history, costume reproduction

## 仓库结构：一个工具 + 三个延伸项目

这个仓库不只放半臂这一件。根目录是**对穿交打版工具链 + 半臂主项目**，
另外两个延伸项目作为子目录并入，共用同一套 `build / export_dxf / preview`
与五图层 DXF 规范 —— 它们本质是这套工具的延伸，不是各自独立的仓库：

| 目录 | 项目 | 裁法 | 与主项目的距离 |
|---|---|---|---|
| （根目录） | 对穿交 **半臂**（钱樟墓夹袄，11 码） | 分裁 | — 主项目 |
| `jiexiu/` | 对穿交 **接袖**（长袖，男装 5 码） | 分裁 | **最近**：衣身一律未动，只加接袖缝 + 4 片 330×222 |
| `shenyi/` | **深衣型矩领**（V1 原衣 / V2 宽袖礼服 / V3 窄袖便服） | 通裁 | 较远：另一种裁剪，无肩缝、无接袖缝 |

三件同属**对穿交**（直领对襟的剪裁 ＋ 交领的穿法，右衽 / 直丝 / 无里布）。
一句话记：**根目录与 `jiexiu/` 差一条袖缝，`shenyi/` 差一整套裁法。**

## 这套东西特别在哪

不是"照着感觉画一张版"，而是每一步都有可复核的闸门：

| 闸门 | 做什么 | 结果 |
|---|---|---|
| 术语锚定 | 先把"对穿交"定义清楚，再动笔 | 推翻过一次方向性错误（见 `PLAN.md` v1.0→v2.0） |
| 量纲锚定 | 官图 → 实测值，优先图纸标注 > 网格 > 图内已知物 > 人体比例 | 3.89 mm/px，各向异性 ≤2% |
| **像素级叠合** | 裁片按真实拼合关系栅格化，与丝博官图做掩膜配准 + IoU/precision/recall | 正视 **0.8717**、背视 **0.8925** |
| 曲线规范 | 三次贝塞尔 + de Casteljau 精确切分 + 腋下 G1 混合圆角 | 消灭"棱角分明" |
| 尺寸自检 | `verification/verify.py` 28 项断言，期望值从 `build.py` 反读，避免两处漂移 | 28/28 PASS |

## 快速开始

```bash
pip install ezdxf            # 唯一第三方依赖（出 DXF 用）

cd pattern

python make.py --sex 女 --size M          # 单码
python make.py --sex 女 --all             # 整档 XS~2XL
python make.py --sex 男 --all             # 男装 S~2XL（厂商表基准）
python make.py --sex 女 --height 163 --bust 86   # 直接给净尺寸
python make.py --sex 男 --size L --ease 宽松     # 放量档
```

产物落在 `out/<profile>_<性别>_<码>/`，同名三件套：`.svg` / `.dxf` / `.pieces.json`。
CAD 里直接 `OPEN` 那个 DXF 即可，毫米单位（`INSUNITS=4`），5 个图层：

| 图层 | 内容 |
|---|---|
| `CUT_轮廓` | 裁片净样闭合多段线 |
| `GRAIN_布纹` | 布纹线（带箭头） |
| `NOTCH_刀口` | 对位刀口 |
| `TEXT_文字` | 片名 ×数量 |
| `DIM_标注` | 100 mm 校验标尺 |

批量重出全部 11 个码：

```bash
python make.py --sex 女 --all && python make.py --sex 男 --all
```

## 两套基准

尺码工具支持两套 profile，`--profile` 不填时按性别自动选：

| 性别 | 默认基准 | 依据 | M 码关键值（mm） |
|---|---|---|---|
| 女 | `artifact` | 钱樟墓文物复原（过审版 v6） | 衣长 825｜平铺胸宽 822｜摆宽 1150｜袖口 195｜领缘 40 |
| 男 | `vendor` | 厂商实物出货尺码表（**最高置信度**） | 衣长 770｜平铺胸宽 570｜摆宽 798｜袖口 160｜领缘 70 |

推档档差取 GB/T 1335.1/.2-2008（身高 5 cm / 胸围 4 cm）。每个参数的出处、独立来源数、置信度见 `verification/尺码资料核验.md`——那里有一条硬口径：**同一篇文章被多站转载只算 1 个来源**。

## 已知残差

1. **袖上缘偏高 ~20 mm**：官图袖上缘自肩向袖口轻微下垂，现按 0.8° 处理，差约 5 px，属作图精度级。
2. **后领高度差 ~25 mm**：官图后领竖直段约 65 mm，本项目领缘条净宽 40 mm（女）/70 mm（男）。成品前建议按 60 mm 复核。
3. **下摆左右角**：摆宽取 1250 略大于官图实测，敏感度测试显示它不是 IoU 主因（1250→1000 仅 +0.5%）。

## 术语与史实备注

- 原件为**左衽**；本项目按用户指定出**右衽**。注意：**右衽不改变裁片**——两襟同形镜像，右衽只决定穿着时哪片在外。
- "对穿交"是民间俗称，非文物定名；定义依据孙韬《孙韬文集》4.3/4.4 与汉服颂《科普汉服领襟分类》。
- 摆宽 1250 并非随手取值：官图实测本就 ≈1150，放量系数 0.92 有客观依据。

## 方法论已沉淀为技能

这套流程不只适用于这件衣服。项目把可复用的部分抽成了一个技能：**[`skill/garment-pattern-cad/SKILL.md`](skill/garment-pattern-cad/SKILL.md)**。

拿它去打任何一件实物（博物馆藏品 / 出土文物 / 手绘裁片稿 / 厂商样衣）都能用。主干是六个动作：

| 动作 | 一句话 | 关键产物 |
|---|---|---|
| 术语锚定 | 先写成 `A = B 的剪裁 + C 的穿法` 这种可判真假的句式，再动笔 | 形制核对表 |
| 量纲锚定 | 标注 > 网格 > 图内已知物 > 人体比例，不许跳级 | mm/px + 各向异性 ≤2% |
| 贝塞尔裁片 | 三次贝塞尔 + de Casteljau 切分 + G1 混合圆角，禁折线近似 | `build.py` |
| 像素叠合闸门 | 掩膜配准 + IoU/precision/recall；≥0.90 优、0.85–0.90 须逐条说明残差 | `overlay.py` |
| 推档 | GB/T 1335 档差 + 放量档；资料按**独立来源数**定置信度 | `sizing.py` |
| 出图 | ezdxf、INSUNITS=4、五图层、中文必须显式建 `simsun.ttc` 样式 | `.dxf` + `.svg` + `.pieces.json` |

技能里还收了 9 条实测踩过的坑（折线近似、命令漏同步三处、"围"当"净平"、小码越界、硬编码文案、DXF 中文乱码、用错标定冤枉好版、按视觉醒目度排残差、把"去袖片"误解成"通袖一片"），以及 §9 的对穿交形制结论——那部分可以直接引用，不用重做论证。

## 常见问题

**Q：能直接拿去裁布做衣服吗？**
能。三件都是**净版**（未含缝份），`DXF` 与 `SVG` 里标了布纹方向、对位刀口和 100 mm 校验标尺 ——
打印后先量那个标尺，误差应 ≤0.5 mm。缝份按常规另加（侧缝 1 cm、下摆 2–3 cm、领缘 1 cm）。

**Q：只有照片、没有尺寸，能做吗？**
可以，前提是图里有可标定的参照物。标定优先级：**图纸标注 > 网格 > 图内已知物 > 人体比例**，不许跳级。
完整方法在 [`skill/garment-pattern-cad/SKILL.md`](skill/garment-pattern-cad/SKILL.md)。

**Q：图纸是什么格式？要不要装 CAD？**
`DXF` 是毫米单位净版（`INSUNITS=4`），AutoCAD / LibreCAD / CorelDRAW 都能开；
不装 CAD 就先看 `SVG` 或 `PNG` 预览。

**Q：「对穿交」和「交领」是一回事吗？**
不是。**对穿交 = 直领对襟的剪裁 ＋ 交领的穿法**（"二次成型"）；术语定义依据孙韬《孙韬文集》4.3/4.4
与汉服颂《科普汉服领襟分类》，见 `PLAN.md`。

**Q：深衣算通裁还是分裁？**
本仓库的深衣（`shenyi/`）是**通裁**：中段一块布上下对折，布带两端就是袖，没有肩缝、没有接袖缝；
裳是另外两段折上来拼在腰线上的。与半臂、接袖（分裁）是两套裁法。
