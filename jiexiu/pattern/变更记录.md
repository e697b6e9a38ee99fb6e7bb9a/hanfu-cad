# 变更记录 · v7（接袖版）

## 一、需求

在 v6 半臂主体上**加接袖**：掩腕袖口 130、领条宽 70、预开领 100，
袖口到袖根是一条**平滑直线**（不是"短袖曲线再另接一段"），男女同款。

## 二、改了什么

| # | 改动 | 具体动作 |
|---|---|---|
| 1 | 袖底缘改直裁 | 删掉 v6 的深凹弧（`U_P1/U_P2` 四点贝塞尔），改为 **腋点 → 腕口下角 一条直线**（14.78°）；接缝处零转折由"同一条线"天然保证 |
| 2 | 新增接袖片 | `sleeve_ext()` ×4：根边垂直（高 222）、袖底为袖底线的延续、腕口垂直（高 130）、四角尖角无圆角 |
| 3 | 衣身袖止于接袖根 | 后片半/前片轮廓在 x=±485 处收一道**垂直直线**（无圆角、无 blend），高度 222 |
| 4 | 预开领 | 前片门襟内端由 `0` 改为 `+NECK/2 = +50`，两片合成 100 通口 |
| 5 | 领缘条 | 宽 40 → **70**；长 = 2×门襟斜边 + 后领口 + 20 = **1729** |
| 6 | 基准档 | 默认 = 厂商实物表 男 M（衣长 770+30=800，通袖 1630，腋深 277） |
| 7 | 尺码表 | 新增 接袖 / 袖根（派生）/ 腕口 三列 |
| 8 | 接袖缝位置（v7.1） | 衣身袖 265 → **200**（`BODY_SL_RATIO = 0.377`），接袖 265 → 330，接缝 x=±550 → **±485**；袖根随之 204 → 222 |

## 三、刻意未动

衣长构成、摆宽 798、单边 534、交叠 270、腋点 285、腋深 277、下摆起翘 60、
门襟斜度、三角拼接 170/140、系带、下摆绢衬条、腋下 R45 圆角 —— 全部沿用 v6。

## 四、踩过的坑（记下来避免重犯）

1. **不要破肩**：袖与衣身联裁，接袖只加在袖上，不能把衣身短袖并进接袖。
2. **不要自造圆角**：接袖两端垂直、四角尖角；v6 里 `_cut_at(R=20)` + `blend` 的两个"神秘圆角"已删。
3. **袖口不是撇出来的**：`Dg` 偏移方向错会让袖口斜甩一块。
4. **预开领要点**：门襟内端必须让到中线外侧（+NECK/2），否则两片合起来仍互相盖住 = "开了个寂寞"。
5. **袖底缘不要分段凑**：先做"短袖弧 + 接袖另起一段"再接 G1，必然出折角；正解是**一条线**再切缝。
6. **袖根与腕口不能同时锁**：袖底为直线时，袖根 = 腕口 + 接袖长·(tan袖底角 + tan落肩)，是派生值。
7. **挪接袖缝要改比例、不要改固定值**：接袖缝位置用 `BODY_SL_RATIO`（衣身袖 / 肩→腕）表达，换码才能等比；
   写死 `JS_LEN` 会让大码接袖短、小码接袖长。
8. **拼合平铺图必须吃同一份参数**：`assembly.py` 曾直接 import build 用 `_DEF` 默认值，
   改完 sizing 后它仍画旧数字。现在通过 `HANFU_PARAMS` 注入 `sizing.params()`，与 `make.py` 完全同源。

## 五、复核

`verification/verify_接袖.py` 27 项 × 5 码 全 PASS（含三点共线 0.00000mm、接缝折角 0.00000mm）。
