# 使用说明 · 对穿交 接袖版（尺码工具 + CAD 出图）

## 一、一条命令出图

```bash
cd pattern

# 单码（男 M，厂商基准）
python make.py --sex 女 --size M

# 整档（女 XS~2XL 共 6 个码）
python make.py --sex 女 --all

# 换基准：vendor=厂商实物表（默认，最高置信度） / artifact=文物复原版
python make.py --sex 女 --size M --profile artifact

# 男装
python make.py --sex 男 --all

# 直接给净尺寸（身高 163、净胸围 86）
python make.py --sex 女 --height 163 --bust 86

# 放量档：紧身 / 合体 / 宽松
python make.py --sex 男 --size 175/92A --ease 宽松

# 指定输出目录
python make.py --sex 女 --all --out ../out
```

产物（`out/<码>/`）：

| 文件 | 内容 |
|---|---|
| `对穿交_接袖_<性别>_<码>.svg` | 裁片图，mm 单位，六图层 |
| `对穿交_接袖_<性别>_<码>.dxf` | **CAD 图**，mm（INSUNITS=4），分 5 个图层 |
| `…pieces.json` | 几何侧车（供二次开发） |

另在 `out/尺码表_vendor_男装.md` 汇总各码尺寸（厂商表为男装）。

## 一·补、两套基准

| 性别 | 自动基准 | 依据 | 中码（M） |
|---|---|---|---|
| **女** | `artifact` | 钱樟墓文物复原（**旧 v6 半臂**，本版未跟进接袖，仅留档） | 衣长 825 ｜ 平铺胸宽 822 ｜ 摆宽 1150 ｜ 袖口 195 ｜ 领缘 40 |
| **男** | `vendor` | 厂商实物出货表（最高置信度） | 衣长 800 ｜ 平铺胸宽 570 ｜ 摆宽 798 ｜ 通袖 1630 ｜ 袖根 204 → 腕口 130 ｜ 领缘 70 |

`--profile` 不填时按性别自动选。**男女同款请统一用 `--sex 男`（vendor 档）**，同一套板型出 5 个码。

厂商表缺的三项：**下摆 = 胸宽×1.40（已确认为正确）**、腋深 = 衣长×0.36、交叠 270。

## 二、DXF 图层

| 图层 | 内容 | 颜色 |
|---|---|---|
| `CUT_轮廓` | 裁片净样闭合多段线 | 白/黑 |
| `GRAIN_布纹` | 布纹线（带箭头） | 灰 |
| `NOTCH_刀口` | 对位刀口 | 红 |
| `TEXT_文字` | 片名 ×数量 | 绿 |
| `DIM_标注` | 100mm 校验标尺 | 青 |

净版：**未含缝份**，裁布时自行加放（下摆 2–3cm、侧缝 1cm、领缘 1cm）。

## 三、尺码表从哪来

- 档差：GB/T 1335.1/.2-2008（身高 5cm、胸围 4cm 分档；女中间体 160/84A、男中间体 170/88A）
- 放量：女 8–10cm 合体 / 男 20–22cm 合身 —— **这一条是单一来源，置信度低**
- 每个参数的出处与置信度见 `verification/尺码资料核验.md`

**基准**：女 M（160/84A 合体）= 已过审的 v6 半臂，其余码都从它推，`make.py --sex 女 --size M` 出来的图与 v6 逐项一致（可当回归测试用）。

## 四、三个可调参数

`pattern/sizing.py` 顶部：

| 参数 | 含义 | 现值 |
|---|---|---|
| `HEM_ADD` | 衣长略加（只加下摆，腋点不动） | 30 |
| `BODY_SL_RATIO` | 接袖缝位置：衣身袖长 /(通袖半 − 肩点)，其余归接袖 | 0.377（M → 衣身 200 + 接袖 330） |
| `NECK_PRE` | 预开领总宽 | 100 |
| `WRIST_DROP` | 腕口 = 袖口 − 该值 | 30 |
| `COL_W` | 领缘宽 | 70 |
| `EASE` | 紧身/合体/宽松 系数 | 0.94 / 1.00 / 1.08 |

袖底缘、袖根、腕口的关系是**几何锁定**的（袖底为一条直线）：
`袖根 = 腕口 + 接袖长 × (tan袖底角 + tan落肩角)`。要改袖根，就改腕口或接袖长。

**想让接袖缝更靠身（衣身短袖更短）** → 调小 `BODY_SL_RATIO`；想让接袖更长 → 调大。
它按比例走，换码时接缝在袖上的相对位置不变。

## 五、回归自检

```bash
# 接袖版专项自检（27 项，逐码跑）
python ../verification/verify_接袖.py ../out/vendor_男_M/对穿交_接袖_男_M.pieces.json

# 拼合平铺图（拼成一件看袖长 / 接缝连续性；全码可出，布局自动跟随衣长/袖长）
python assembly.py --sex 男 --size M      # → out/vendor_男_M/拼合平铺图.svg

# 出 PNG 预览（Edge 无头，1:1）
python preview.py 男 M                    # → 预览_拼合平铺图.png / 预览_裁片图.png

python sizing.py                          # 打印男女全码尺寸表
```

已跑的实测结果：S / M / L / XL / 2XL **27 项全 PASS**（2026-10-29）。
