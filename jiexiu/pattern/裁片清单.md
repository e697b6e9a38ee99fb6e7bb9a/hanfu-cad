### 接袖缝位置为什么是 200（而不是把衣身留到 265）

衣身袖长取 **0.377 × (通袖半 − 肩点)**，其余归接袖：

```
M：通袖半 815 − 肩点 285 = 530（肩点 → 腕口）
    衣身袖 200（0.377×530） ＋ 接袖 330 ＝ 530  ✓
接袖缝 x = ±(285 + 200) = ±485
```

0.377 是「原短袖版袖长 265 / 上一版肩→腕 700」的比例，用来**保持接袖缝在袖上的相对位置**
不随码偏移；嫌衣身袖长就把这个系数往下调（见 `使用说明.md` 可调参数表）。

### 袖根为什么是 222 而不是 160

袖底缘按直裁（腋点直通腕口下角的一条直线），袖根边高由几何决定：

```
袖底角 = atan[(腕口下角高 − 腋点高) / (通袖半 − 肩点)] = 14.78°
袖根  = 腕口 130 + 接袖长 330 × (tan 14.78° + tan 0.8°) = 221.7 → 222
```

厂商表里的「袖口 160」是**原短袖版**的袖口宽；本版袖口收窄到 130（掩腕），
袖根随直线袖底自然变成 222。这两个数是同一几何的必然结果，不能同时锁定——**袖根是派生值**。

## 五、缝制要点

1. **接袖缝**：衣身袖口（x=±485 竖边，高 222）与接袖根边对位缝合，上下角打刀口。
2. 接袖缝好后，袖底缘应是一条**笔直的线**，不得有台阶或折角——这是本版的验收要点。
3. 门襟边必须是直丝；后中缝先拼，缝线贯通至下摆。
4. 领缘从前襟下端起，经门襟绕后颈回另一侧，一条不断；预开领 100 由两前片让口形成。
5. 系带两根装前襟（非身侧）；下摆内镶绢衬，先固定衬条再折边。
6. 净版未含缝份：下摆 2–3cm、侧缝 1cm、接袖缝 1cm、领缘 1cm。
