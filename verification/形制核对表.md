## 一、术语锚定（可判真假的句式）

| 名 | 定义 |
|---|---|
| **原始直领交襟衣**（V1） | 直领对襟的剪裁 + 交襟的穿法。一件由多匹拼幅、上下对折、前中剪开的直领长衣 |
| **矩领短衣**（V2） | 在 V1 的**左右领口各剪去一段**，平铺成"矩领对襟"短衣；仍交襟穿 |
| **深衣型矩领**（V3） | V1 的对襟身 + **下裳错位半幅拼合**；"矩"的折角来自下裳与上衣错位拼合，不是领襟固定点 |
| 以折代剪 | 肩线靠**上下对折**折出，**不另裁前片后片**；领口不挖，靠折叠/剪开形成 |
| 袖腰分离 | 原始深衣来自交领被衣的改良；**袖根与腰线相邻**。窄袖深衣腰线被抬到高腰甚至齐胸 |

## 五、待核对 / 已知残差

1. 陶俑（`fig_深衣型矩领_剪裁与平铺.jpg` 下半）：衣身与下裳接缝在**齐胸高腰**位置（V 领尖端正好落在这条接缝上）——V3 用。
2. 红线"下裳错位延伸"：陶俑上量得错位量 ≈ 55 px，相对幅宽 ≈ 半幅；A 裁剪图上红线长 56 px、右端贴中央线 —— 两处一致，**错位 = 半幅**。
3. **③ 中央 5 条竖线的正确读法**（2026-10-29 用户纠正，第三轮才对）：

   ```
   704 ─┬─ 领条（40 宽）
   723 ─┴─ 后片露出边界
        │  露出的后片（80 宽）
   742 ─┼─ 后中缝（后片本身的拼缝，居中）
        │
   760 ─┬─ 领条（40 宽）
   778 ─┴─ 开口另一边
   ```

   即中央是 **`|领条| 露出的后片 |领条|`** 三段，不是"一条 160 宽的领子"。
   **为什么中间能露出后片**：上下对折、后片是整块；前中一剪开（160），
   正对着的就是后面的后片 —— 所以中间那条线是**后中缝**。
4. **折的量是 40，不是 80**：两襟各向里折 40，布边落在 ±40，中间正好露出后片 80
   （＝ 160 − 40×2）。折边区（±80→±40）就是领条的缝位。
5. **领条 = 一条直的（1700 × 95），成型后呈倒 U**：左襟 → 绕颈 → 右襟。
   ④ 平铺图上顶部那道梯形（底 160 / 顶 89 / 露出 77）＝ **领条在领口向上折转**的那一段，
   不是后领、也不是领窝开口。

## 六、腋下（钩形记号）—— 2026-10-29 高分辨率重测

数据源换成 `sources/fig_深衣型矩领_剪裁与平铺.jpg`（1279×1920），
按 1 幅 = 102 px（剪裁图）/ 99 px（平铺）标定 → **4.875 mm/px**，两图同尺度，
且 衣长 624 对 129 px、段高 1248 对 256 px 均自洽。

| 量到的东西 | 数值 | 说明 |
|---|---|---|
| 剪裁图：中段 4 幅的分界 | x = −1000 / −500 / 0 / +500 / +1000 | 5 条**通高**竖线，没有别的竖线 |
| 剪裁图：钩形记号 | x = −424 … −351（宽 73），自段边内伸 **195** | 上段边下沿、下段边上沿各一对（折后即腰线） |
| 平铺：钩形记号 | 竖段在 **±368**（左 −361 / 右 +375），自腰线上 **205**，下端弯出到 **±424 … ±458** | 虚线 |
| 平铺：腰线 | 一条连续的横线，**腋下没有任何横向缝线** | 多余的是我上一版加的 |
| 平铺：裳的腰口 | ±366 | 比钩形记号的脚（±424）**内收 58** |

结论（＝用户原话）：`(袖子缝合) | (躯干衣身边缘)` 两条线**在腋点共顶点**；
不加缝合 → 袖到衣身全敞口、侧视**倒 U**；加了 → 侧视**闭成 0**。
所以图上只画那个钩：竖段＝躯干衣身边缘（200），末端外弯 60 落在腰线上，
弯点即腋点；腰线外段（±430 以外到袖口）＝袖底缝。**腰线上不另画横线、腋点不画圆圈。**

## 八、V3 窄袖深衣（2026-10-29，用户：「将衣部分的长度缩小，直到袖口为窄袖大小」）

原文（孙韬《拒绝碰瓷，一篇文章说清楚西周矩领》）：

> 原始深衣来自于对原始交领被衣的改良，是交领被衣袖腰分离的产物。所以古深衣的袖和腰位置是相邻的。
> 宽袖深衣的腰线在正常位置，但如果是窄袖深衣呢？**窄袖深衣的腰线，实为高腰甚至齐胸位置。**
> 其衣身剪裁和上身拼缝对应效果如下〔图〕

**关键：这件衣服的袖肥 ＝ 衣长 ＝ 袖口宽，是同一个数**（上衣就是中段对折出来的那条布带，
袖子是它的两端，所以袖口的开口高度＝带子高度＝衣长）。因此"把衣身缩短"会同时：
袖口变窄 → 成为窄袖；腰线（衣身接缝）上抬 → 齐胸。

所以宽袖↔窄袖 **只有一个旋钮：L_BODY**；成衣长短是第二个旋钮 `GARMENT_L`。

| | L_BODY（衣长＝袖口） | 中段 | 裳（上段/下段各） | 腰线 | 成衣总长 | 定位 |
|---|---|---|---|---|---|---|
| V2 宽袖（已存档） | 624 | 1248 | 1248 | 自然腰 | 1872 | **礼服** |
| **V3 窄袖** | **195** | **390** | **575** | **齐胸** | **770** | **便服（普通外套长度）** |

**为什么这么配是合逻辑的**（用户 2026-10-29 点破）：
礼服要庄重 → 宽袖；窄袖本身就是便服的特征。原文自己也是这么分的——
- 「前者（宽缘边方领＋下裙＋蔽膝）是贵族的**衣裳制礼服**，后者（中长衣、露出裤腿）是仆从的**深衣制便服**」；
- 「**宽袖**深衣的腰线在正常位置，但如果是**窄袖**深衣呢？窄袖深衣的腰线，实为高腰甚至齐胸」。
所以：宽袖 ↔ 腰线正常 ↔ 礼服（V2，1872 及踝）；窄袖 ↔ 腰线齐胸 ↔ 便服（V3，770 外套长度）。
两件是同一套板型的两个档，不是两件不相干的衣服。

- 195 取自本项目既有口径：`hanfu-cad/pattern/sizing.py`「窄袖口 ≈(净胸围+放量)/6」，M 码袖口 195。
- 770 取自厂商实物实测表男 M 衣长（同表 S 730 / M 770 / L 810），即"普通外套"长度。
- 布片高 ＝ 中段 390 + 上段 575 + 下段 575 ＝ **1540**（不再是 3744）。
- 腋下记号的竖向尺寸随衣长等比缩（×195/624）：垂线 200→62.5，弯折段 70→21.9，外弯仍 60。
- 回归：`HANFU_PARAMS='{"L_BODY":624,"GARMENT_L":1872}'` 可原样还原 V2（中段 1248 / 裳 1248 / 腋点 200）。

V3 交付物：`out/深衣型矩领_V3_窄袖.svg｜.pieces.json｜.dxf`、`out/预览_V3_窄袖.png`、
对照 `out/_cmp_v2_v3.png`（由 `pattern/make_cmp.py` 生成，两件严格同比例）。
DXF 实测：5 图层、mm、4 片（2000×390 / 2000×575 ×2 / 1700×95）、29 刀口。
